ℹ️ About This Tool

Every Cost. Explained.

Built by Kevala Home for West Bengal property buyers.

💡 What This Calculator Covers

  • Stamp Duty — 5–7% state tax, tiered by location & value
  • Registration Fee — 1.1% effective rate (mandatory)
  • GST — 0%, 1%, or 5% depending on property status
  • Mutation — KMC ~₹20/sqft; rural nominal
  • Legal / Advocate Fee — market estimate 0.5–1%
  • Brokerage — 1% from buyer for resale (nil for new builder)
  • Deed Writer & Incidentals — ₹5k–15k
  • TDS Alert — 1% for properties above ₹50L

📋 Rate Update System

All rates are stored in a config.json file hosted on GitHub. Whenever stamp duty, GST, or any charges change, just update that one file — the app refreshes automatically within minutes. No app store update needed.
